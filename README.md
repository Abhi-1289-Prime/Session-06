# Prompt Engineering Session 06: Classwork (CW)

## Overview

This folder contains the classwork completed during Session 06. The main objective of this lab was to understand AI-assisted programming with the **Cursor AI editor**, with an emphasis on safe code refactoring, checking program output, and setting up persistent AI coding rules.

## Objectives Achieved

1. **Exploring AI Modes:** Learned the difference between Cursor's "Understand-only" (Chat) mode, used for analyzing code logic, and "Inline Edit" mode, used for quickly generating and modifying code.
2. **Code Refactoring:** Improved the structure of a poorly organized Python program (`messy_report.py`) with AI assistance by introducing meaningful variable names, f-strings, and reusable functions while preserving its original functionality.
3. **Output Verification:** Compared the output of the refactored program with the original baseline output character-by-character to confirm that no unintended changes occurred.
4. **Creating Custom AI Rules:** Set up custom Python coding standards using Cursor's `.mdc` rule system and checked whether the AI followed those standards while generating additional code.

## Repository Contents

### Source Code

* **`messy_report.py`**: The original unstructured Python script provided for the lab exercise.
* **`refactored_script.py`**: The improved version of the script, rewritten using cleaner code and Python best practices.

### Documentation & Evidence

* **`original_output.txt`**: Contains the terminal output from the original script and serves as the reference for comparison.
* **`verification_note.txt`**: Records the verification that the refactored script produces output identical to the original version.
* **`ai_modes_observation.txt`**: Includes observations about when Cursor's Chat and Inline Edit modes are most useful.
* **`rules_comparison_table.md`**: Provides a comparison table with evidence showing whether Cursor AI followed the custom coding rules when asked to add new code.
